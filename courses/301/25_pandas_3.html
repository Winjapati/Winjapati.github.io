Step 0: Rebuild alice_df

import re
import pandas as pd

# Stopwords (from Day 18)
stopwords = ["the", "to", "and", "of", "a", "her", "i", "in", "was", "it",
             "she", "he", "be", "that", "you", "not", "had", "as", "his", "for",
             "with", "is", "have", "but", "at", "so", "all", "my", "been", "him",
             "on", "by", "could", "would", "very", "no", "what", "which", "they",
             "were", "there", "me", "an", "must", "this", "said", "from", "or",
             "will", "any", "much", "than", "such", "their", "them", "if", "do",
             "did", "one", "when", "your", "more", "are", "we", "who", "up",
             "out", "down", "into", "s", "t"]

# 1. Load Alice and cut off the Gutenberg header and footer
with open("../../data/gutenberg/alice.txt", "r", encoding="utf-8") as f:
    alice_lines = f.readlines()

while not alice_lines[0].startswith("*** START"):
    alice_lines = alice_lines[1:]
alice_lines = alice_lines[1:]

while not alice_lines[-1].startswith("*** END"):
    alice_lines = alice_lines[:-1]
alice_lines = alice_lines[:-1]

alice_text = "".join(alice_lines)

# 2. Split into chapters (and drop everything before Chapter I)
chapters = re.split(r"\nCHAPTER [IVXL]+", alice_text)
chapters = chapters[1:]

# 3. One row per word, with its chapter
rows = []
chapter_num = 0

for chapter in chapters:
    chapter_num += 1
    words = re.split(r"[\W_]+", chapter.lower())   # split on \W AND on _
    words = [w for w in words if w != ""]
    for w in words:
        rows.append({"word": w, "chapter": chapter_num})

alice_df = pd.DataFrame(rows)

# 4. Save it for next time
alice_df.to_csv("alice_words.csv", index=False, encoding="utf-8-sig")

Watch Out!

  • Inside df[ ... ], each piece has to be a True/False test:
content[content["chapter"] == 1]     # a test: True or False for each row
content[content["word"]]             # NOT a test: just the column. Error!
  • .value_counts needs its parentheses: .value_counts()
  • Pick a column before you count: ch1_content["word"].value_counts()
    • On the whole table, .value_counts() counts word + chapter pairs, not just words

Grouping

The Old Way

  • In Detective Gutenberg, you found the average word length of two books:
alice_total = 0
for w in alice_words:
    alice_total += len(w)
print(alice_total / len(alice_words))

mp_total = 0
for w in mansfield_words:
    mp_total += len(w)
print(mp_total / len(mansfield_words))
  • …and a third book meant copying it all again.
  • (Don’t run this code: it’s just a reminder.)

The Pandas Way: .groupby()

books.groupby("text")["length"].mean()
  • Read it left to right:
    1. books.groupby("text"): split the rows into groups by text
    2. ["length"]: in each group, take the length column
    3. .mean(): average it
  • One line, however many books are in the table.

Other Things to Do with Groups

  • Run each of these:
books.groupby("text").size()                # how many rows (tokens)?
books.groupby("text")["word"].nunique()     # how many types?
books.groupby("text")["length"].max()       # longest word?
  • Question: Mansfield Park has about 3 times as many types as Alice. Does that mean Austen has a richer vocabulary?
  • Not necessarily! Mansfield Park is about 6 times longer. A longer book has more chances to use new words.
  • Comparing raw counts across texts of different sizes is a trap…

Counting Fairly

Raw Counts Mislead

books[books["is_ly"]]["text"].value_counts()
  • Check: Mansfield Park has about 2,700 -ly words; Alice about 430
  • So Austen loves -ly words way more than Carroll?
  • Remember Day 20: we compare rates, not raw counts

Rates with .mean()

  • Here’s a trick: Python counts True as 1 and False as 0
books.groupby("text")["is_ly"].mean()
  • So the mean of a True/False column = the proportion of rows that are True
  • Multiply by 1,000 for a rate per 1,000 words:
ly_rate = books.groupby("text")["is_ly"].mean() * 1000
ly_rate
  • Look at the two rates. What happened to the big difference?
  • It mostly disappeared: about 16 vs. 17 -ly words per 1,000. The two writers are nearly the same!

Proportions with .value_counts()

  • .value_counts() can give proportions instead of counts:
alice_df["word"].value_counts(normalize=True).head(10)
mp_df["word"].value_counts(normalize=True).head(10)
  • Now we can compare the two books fairly, word by word.
  • Check: the is #1 in both books: about 6% of Alice, about 4% of Mansfield Park

Cheat Sheet 2: Filtering

  • Pattern: df[ test ] keeps the rows where the test is True
df[df["word"] == "queen"]                 # equals
df[df["word"] != "under"]                 # does not equal
df[df["word"].str.endswith("ly")]         # ends with
df[df["word"].str.startswith("un")]       # starts with
df[df["word"].isin(stopwords)]            # is in a list
df[~df["word"].isin(stopwords)]           # ~ flips it: NOT in a list

df[(df["word"] == "queen") & (df["chapter"] == 8)]    # & = and
df[(df["word"] == "king") | (df["word"] == "queen")]  # | = or
  • Each condition gets its own parentheses

Cheat Sheet 3: Counting & Sorting

df["word"].value_counts()                  # count each value, most common first
df["word"].value_counts().head(10)         # top 10
df["word"].value_counts(normalize=True)    # proportions instead of counts
df["chapter"].value_counts().sort_index()  # sort by the label (1, 2, 3...)

df["word"].nunique()                       # how many unique values (types)
df["length"].mean()                        # average
df["length"].max()                         # biggest

df.sort_values("length", ascending=False)  # sort rows, biggest first
df.drop_duplicates("word")                 # keep one row per word
