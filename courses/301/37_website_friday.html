An iframe Embeds Another Page

  • An iframe (inline frame) displays another web document inside your page.
  • <a href="..."> sends you to another page.
  • <img src="..."> displays an image.
  • <iframe src="..."> displays an embedded page or player.
  • The content still comes from the other website: you’re not copying it into your repo.

What Can You Embed?

  • A YouTube video: Share → Embed → copy the iframe code.
  • A map: OpenStreetMap (Share → HTML) or Google Maps (Share → Embed a map).
  • Some interactive charts, presentations, and other web resources.
  • Not every site permits embedding. A normal webpage URL often won’t work; look for the site’s Embed option.

Hunt 1: Possible Answer

  1. <iframe>. Its src, like <img>’s, says where to find something.

  3. The video shrinks with the window. (aspect-ratio keeps its shape.)
  4. With watch?v=, YouTube refuses to be embedded.
  5. The embed/ address: the one YouTube allows in an iframe.

CSS Grid

.cards {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 16px;
}
  • display: grid arranges children into a grid.
  • grid-template-columns defines the columns.
  • fr means a fraction of the available space.
  • gap separates the boxes, just like in Flexbox.
  • Good for projects, publications, interests, and image galleries.

Hunt 2: Possible Answer

  4. The middle column is twice as wide as the others.
  5. More space appears between the cards.
  6. Its cards use the same classes, so the same rule styles both pages. No new CSS!

Responsive Design

  • A responsive website adapts to the size of the screen.
  • A media query applies CSS only when a condition is true.
@media (max-width: 600px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
  • At 600px wide or less, the grid switches to one column.
  • The HTML stays the same: only the CSS changes.

Responsive Design

  • On a real phone, this line in the <head> is what makes media queries work:
<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Without it, phones pretend to be a wide desktop screen and shrink the whole page.
  • It’s been in every <head> since Monday: make sure it’s in yours!

Hunt 3: Possible Answer

  1. My photo moves above the text, and the edges get less padding.
  2. Less padding in the header and main; the profile stacks (flex-direction: column); the cards become one column.
  3. The cards now stack at 900px, while the window is still fairly wide.
  4. When two rules conflict, the later one wins. Putting the media query last lets it override the rules above it.
