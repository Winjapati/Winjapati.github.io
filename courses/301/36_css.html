HTML vs. CSS

  • HTML says what things are: a heading, a list, a link
  • CSS says how things look: color, font, size, spacing
  • Without style.css, the page still has all its content: just none of its look.

A CSS Rule

h2 {
  color: #7a4e8c;
  border-bottom: 2px solid #e0d4e6;
}
  • h2 is the selector: which elements to style
  • color and border-bottom are properties; #7a4e8c and 2px solid #e0d4e6 are their values
  • Each property ends with ;, and the whole rule goes inside { }

Colors

  • #7a4e8c is a hex code: red, green, and blue, from 00 (none) to ff (full)
    • 7a red, 4e green, 8c blue: a plum
  • You can also use names: white, tomato, rebeccapurple…
  • In VS Code, hover over a color in style.css to get a color picker.

Hunt 1: Possible Answer

  1. All the color, fonts, and layout disappear: plain black text on white. All the content is still there.
  2. header { background-color: #7a4e8c; ... }: a selector, then properties and values inside { }.
  3. The plum color and the line belong to the h2 rule. An <h3> isn’t an h2, so the rule doesn’t apply.
  4. In header, h2, and a. VS Code shows a little color box and a color picker.
  5. All three pages change: they all load the same style.css.

Kinds of Selectors

Selector Styles… Example
h2 every <h2> h2 { color: ... }
.note every element with class="note" <p class="note">
nav a every <a> inside a <nav> the links in the menu
th, td every <th> and every <td> the table cells
  • A . means class. The class name is up to you!

Classes

<p class="note">Most of the tea is in Chapter 7...</p>
.note {
  background-color: #f3e9dc;
  border-left: 5px solid #a0673a;
  padding: 10px 16px;
}
  • class is an HTML attribute; .note is the CSS selector that finds it.
  • Any element with class="note" gets the box.

Hover

nav a:hover {
  text-decoration: underline;
}
  • :hover styles an element only while the mouse is over it.

Every Element Is a Box

  • content: the text itself
  • padding: space inside the box
  • border: the edge of the box
  • margin: space outside the box

Side by Side: flex

nav ul {
  display: flex;
  gap: 24px;
}
  • Normally, boxes stack on top of each other.
  • display: flex puts the boxes inside it in a row; gap puts space between them.

Hunt 3: Possible Answer

Every Website’s CSS Is Visible

  • Your browser has to download a site’s CSS to show it to you.
  • So you can see – and learn from – the CSS of any website.
  • CSS can live in a separate file (like style.css), or inside a <style> tag in the <head>.

How to Borrow a Style

  1. Go to a website whose look you like.
  2. Right-click on a heading (or a button, or the page background) and choose Inspect.
  3. In the Styles panel, find properties like font-family, color, background-color, font-size.
  4. Copy them into a rule in your style.css, with a comment saying where they came from.

What Can Go Wrong?

  • Fonts: a site may use a font you don’t have. Your browser quietly uses the next one on the list.
  • Selectors: their CSS refers to their class names, not yours.
  • Variables: a value like var(--fg) points somewhere else. Find --fg to get the real value.
  • Too much: a big site’s CSS can be thousands of lines. Borrow a few properties, not the whole file.
  • Fair use: borrow styles to learn, not logos, images, or whole designs.

Hunt 4: Possible Answer

  1. Properties you know: font-size, line-height, color… The font is usual, sans-serif: usual is a font you probably don’t have!
  2. In a variable: --color-wildcat-blue: rgba(0,51,160,1). That’s 0 red, 51 green, 160 blue: the same color as #0033a0.
  3. From two long .css files, with machine-made names like css_O3K_HbzDV...css.
  4. From a <style> tag inside index.html itself.
  5. The link gets a light background: nav a:hover { background: #eef1fb }. Its color is var(--fg), a variable defined at the top, in :root.
