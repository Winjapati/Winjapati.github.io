Lists of Dicts

Another Way to Nest

  • A nested dict needs a unique key for each item
  • But what if two items share a name?
lexicon = {
    "bank": {"pos": "noun", "gloss": "edge of a river"},
    "bank": {"pos": "noun", "gloss": "place to keep money"}
}
print(lexicon)
  • What happened to the river?

A List of Dicts

  • Instead, we can make a list, where each item is a dict:
lexicon = [
    {"form": "bank", "pos": "noun", "gloss": "edge of a river"},
    {"form": "bank", "pos": "noun", "gloss": "place to keep money"},
    {"form": "bank", "pos": "verb", "gloss": "to tilt an airplane"}
]
  • Each dict is one entry: one row of a table
  • Each key ("form", "pos", "gloss") is a column

Looping Through a List of Dicts

  • Since it’s a list, we loop through it as normal; each item is a dict:
for entry in lexicon:
    print(entry["form"], "(" + entry["pos"] + "):", entry["gloss"])
  • And lexicon[2]["gloss"] gives us…?

Building a List of Dicts

  • We build one with .append(), just like any list
  • Let’s turn our review activity’s lang_info into a list of dicts:
lang_rows = []

for lang, info in lang_info.items():
    lang_rows.append({
        "language": lang,
        "family": info["family"],
        "location": info["location"]
    })

print(lang_rows)

Dict of Dicts vs. List of Dicts

Dict of dicts List of dicts
Looks like {"p": {...}, "b": {...}} [{...}, {...}]
Find one item Fast: d["p"] Loop and check
Keys Must be unique Duplicates are fine
Good for Lookup tables, inventories Entries, tokens, rows

Tables Everywhere

  • Look at lang_rows: every dict has the same keys
  • That’s really a table: rows = languages, columns = keys
  • Python has a library built just for tables…

Setting up Pandas

Installing Pandas

  • PC:
pip install pandas
  • Mac:
pip3 install pandas

Loading Pandas

  • To use it in Python:
import pandas as pd
  • pd is just a nickname, so we don’t have to type pandas every time
  • Like re, Counter, and matplotlib, pandas is a library: a bundle of extra tools someone else wrote

⚠️ Avoid file-name shadowing: Don’t name your scripts pandas.py, re.py, random.py, etc.

What is Pandas?

  • pandas is the standard Python library for working with tables
  • Lexicons, word lists, corpora, survey results: if it could live in a spreadsheet, pandas can handle it
  • For us, pandas does three jobs:
    1. Turn our Python data into a table
    2. Save that table as a file (and load it back)
    3. Ask questions of it (next week!)

From List of Dicts to Table

Your First DataFrame

  • A pandas table is called a DataFrame (df for short)
  • Remember lang_rows? Watch this:
import pandas as pd

lang_df = pd.DataFrame(lang_rows)
print(lang_df)

What Just Happened?

  • Each dict in the list became a row
  • Each key became a column
  • The numbers on the left (0, 1, 2, 3) are the index: pandas numbers the rows for us
  • A single column of a DataFrame is called a Series

Another Way: Column by Column

  • Sometimes our data comes as separate lists, one per column (like on Monday!)
  • A dict of lists works too: each key is a column name, each list is that column’s values
fresh_df = pd.DataFrame({
    "language": ["Latin", "Greek", "Sanskrit", "Finnish"],
    "family":   ["Indo-European", "Indo-European", "Indo-European", "Uralic"],
    "location": ["Italy", "Greece", "India", "Finland"]
})

print(fresh_df)
  • Same table! Which way is easier depends on what shape your data is already in.

What If a Key Is Missing?

rows = [
    {"form": "aqua", "gloss": "water"},
    {"form": "canis", "gloss": "dog", "pos": "noun"}
]

print(pd.DataFrame(rows))
  • What does pandas put in the empty cell?
  • NaN = “Not a Number,” pandas’ way of saying no data here

Saving & Loading Tables

Saving Your Table

  • We can save a df as a .csv file that opens in Excel or Google Sheets:
lang_df.to_csv("languages.csv", index=False, encoding="utf-8-sig")
  • index=False leaves out the 0, 1, 2… index
  • utf-8-sig makes Excel display characters like ō and ʰ correctly
  • Open languages.csv in Excel. What does it look like?

Loading It Back In

  • And we can read a .csv back into a df:
check = pd.read_csv("languages.csv")
print(check)
  • This is how you’ll start Component 3: by loading the .csv you save in Component 2.

The Whole Pipeline

  1. Start with your data (lists, a text file…)
  2. Clean it into a list of dicts (one dict per row)
  3. pd.DataFrame() it
  4. .to_csv() it
  5. pd.read_csv() it back to check
  • That’s Project Component 2!
