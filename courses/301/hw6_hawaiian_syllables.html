Some Hawaiian Phonology

Hawaiian has one of the smallest sound inventories of any language:

  • 8 consonants: h, k, l, m, n, p, w, and the ʻokina ʻ, a glottal stop ([ʔ])
  • 5 vowels: a, e, i, o, u, each of which can also be long. A long vowel is written with a kahakō (macron): ā, ē, ī, ō, ū

Hawaiian syllables are very simple: every syllable is either a vowel (V) or one consonant plus a vowel (CV). There are no consonant clusters, and no word ends in a consonant. So a word like aloha breaks up like this:

Word Meaning CV pattern Syllables
aloha love; hello; goodbye VCVCV a.lo.ha
ʻohana family CVCVCV ʻo.ha.na
nēnē Hawaiian goose CVCV nē.nē
kīlauea Kīlauea (the volcano) CVCVVVV kī.la.u.e.a

Two things to notice:

  1. The ʻokina is a consonant, just like h or k.
  2. A long vowel like ē counts as one vowel.

(Real Hawaiian treats some vowel pairs, like the au in kīlauea, as a single diphthong. For this assignment, every vowel is its own syllable. See the challenge at the end if you want to do better.)

Part 1: Write Your Functions

Write these four functions in lin301.py. Each one should return its answer, not print it. Test each one on a few words where you already know the answer before you move on.

  1. is_vowel(letter) takes one letter, and returns True if it is a Hawaiian vowel (short or long), and False otherwise.
    • is_vowel("a") → True
    • is_vowel("ū") → True
    • is_vowel("k") → False
    • is_vowel("ʻ") → False
  2. cv_pattern(word) takes a word, and returns a string with "C" for every consonant and "V" for every vowel. It must use is_vowel().
    • cv_pattern("aloha") → "VCVCV"
    • cv_pattern("ʻohana") → "CVCVCV"
  3. syllabify(word) takes a word, and returns a list of its syllables. It must use is_vowel(). (Hint: in Hawaiian, a syllable always ends with a vowel.)
    • syllabify("aloha") → ["a", "lo", "ha"]
    • syllabify("kīlauea") → ["kī", "la", "u", "e", "a"]
  4. count_syllables(word) takes a word, and returns how many syllables it has. It must use syllabify().
    • count_syllables("aloha") → 3
