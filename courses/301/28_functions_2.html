What Happens Inside a Function

Variables Inside Stay Inside

  • After running load_words(), we can try to look at one of its variables:
alice_words = load_words("alice.txt")
print(lines)

Variables Inside Stay Inside

  • lines only exists while the function runs. When it returns, its variables are gone.
  • Only the return value gets out
alice_words = load_words("alice.txt")
print(lines)

Why That’s a Good Thing

alice_words = load_words("alice.txt")
mansfield_words = load_words("mansfield_park.txt")
  • Both calls make their own lines, text and words
  • They never step on each other, so we don’t need alice_lines, mansfield_lines, odyssey_lines…
  • Each call starts fresh

import os

HERE = os.path.dirname(__file__)   # the folder lin301.py lives in: data/

stopwords = ["the", "to", "and", "of", "a", "her", "i", "in", "was", "it",
             "she", "he", "be", "that", "you", "not", "had", "as", "his", "for",
             "with", "is", "have", "but", "at", "so", "all", "my", "been", "him",
             "on", "by", "could", "would", "very", "no", "what", "which", "they",
             "were", "there", "me", "an", "must", "this", "said", "from", "or",
             "will", "any", "much", "than", "such", "their", "them", "if", "do",
             "did", "one", "when", "your", "more", "are", "we", "who", "up",
             "out", "down", "into", "s", "t"]

def ttr(words):
    return len(set(words)) / len(words)

def ttr_first(words, n=10000):
    return len(set(words[:n])) / len(words[:n])

def avg_word_len(words):
    total = 0
    for w in words:
        total += len(w)
    return total / len(words)

def ly_rate(words):
    count = 0
    for w in words:
        if w.endswith("ly"):
            count += 1
    return count / len(words) * 1000

def stopword_rate(words, stopwords):
    count = 0
    for w in words:
        if w in stopwords:
            count += 1
    return count / len(words)

def load_text(filename):
    with open(os.path.join(HERE, "gutenberg", filename), "r", encoding="utf-8") as f:
        lines = f.readlines()
    while not lines[0].startswith("*** START"):
        lines = lines[1:]
    lines = lines[1:]
    while not lines[-1].startswith("*** END"):
        lines = lines[:-1]
    lines = lines[:-1]
    return "".join(lines)

def load_words(filename):
    text = load_text(filename)
    words = re.split(r"[\W_]+", text.lower())
    return [w for w in words if w != ""]

def report(title, words):
    print(title, "TTR:", ttr(words))
    print(title, "TTR (10,000 words):", ttr_first(words))
    print(title, "Average Word Length:", avg_word_len(words))
    print(title, "-ly words per 1,000:", ly_rate(words))
    return ttr_first(words)

def book_to_df(filename, label):
    text = load_text(filename)
    chapters = re.split(r"(?im)^\s*CHAPTER\s+(?:[IVXLCDM]+|\d+)\b", text)
    chapters = chapters[1:]
    rows = []
    chapter_num = 0
    for chapter in chapters:
        chapter_num += 1
        words = re.split(r"[\W_]+", chapter.lower())
        words = [w for w in words if w != ""]
        for w in words:
            rows.append({"word": w, "chapter": chapter_num})
    df = pd.DataFrame(rows)
    df["text"] = label
    return df

def add_columns(df, stopwords):
    df["length"] = df["word"].str.len()
    df["is_ly"] = df["word"].str.endswith("ly")
    df["is_stopword"] = df["word"].isin(stopwords)
    return df

Wrapping Up

How to Write a Function

  1. Find the code you repeated
  2. What changes each time? Those are your parameters
  3. What do you need back? That’s your return
  4. Test it on something small, where you already know the answer

If You Get Stuck

Common Errors

  • NameError: name 'load_text' is not defined: run the chunk with its def first. A function can only use functions Python already knows.
  • NameError: name 'lin301' is not defined inside lin301.py: drop the lin301. in front of function names inside the file
  • NameError: name 'pd' is not defined (from lin301.py): add import pandas as pd to its header

Common Errors

  • Your change to lin301.py isn’t showing up: save the file, Restart the notebook, and rerun the import
  • NameError: name 'stopwords' is not defined: copy the stopwords list from Day 25 and run it
  • KeyError: 'word': book_to_df() built an empty table (0 chapters). Check how your book marks its chapters.
  • Your function returns None: is return the last line, and indented inside the def?
  • return inside the for loop: the function stops after the first chapter. Un-indent it!
