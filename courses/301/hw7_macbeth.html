The Assignment

You’ll compare Shakespeare’s Macbeth in English, in a language written in the Latin alphabet (Finnish), and in a language written in a non-Latin script (Greek). Using spaCy, WordNet, and pandas, you’ll build a table for each version, then choose two ways to compare them, and explain what you find.

Make a Quarto document called hw7_macbeth_lastname_firstname.qmd in your homework/hw7 folder, and import your functions from lin301.py the way we do in class. As always, explain in your own words what your code does, and say whether and how you used any AI tool. (The syllabus does not allow GenAI to write your homework solutions.)

Greek Dimitrios Vikelas (1896) ebook 34434 macbeth_el.txt ΠΡΑΞΙΣ ΠΡΩΤΗ

Each file must contain only the play before you analyze it:

  • The English file begins with a table of contents whose lines also start with ACT. Delete it.
  • The Greek file ends with the translator’s notes (starting at the heading ΣΗΜΕΙΩΣΕΙΣ, after ΤΕΛΟΣ ‘The End’). Delete them, but keep the *** END line.

You will also need the spaCy models fi_core_news_sm and el_core_news_sm, and the omw-2.0 WordNet data.

Part 1: Build Your Tables

Make one DataFrame per language with book_to_spacy_df(), with one chapter per act. Show that each table has exactly 5 acts, and give the number of words in each version.

Part 2: Investigate (Choose Two)

Choose two of these five investigations. For each, show your code and results, and write a short paragraph explaining what you found and why.

A. Parts of speech. Choose three parts of speech. How many of each are there per 1,000 words in each version? Explain the biggest difference.

B. Morphology. Choose one feature: case in Finnish (Nom, Gen, Par, Ine, Ela, Ill, Ade, Abl, All, Ess, Tra), or gender (Masc, Fem, Neut) or case (Nom, Gen, Acc, Voc) in Greek. Count the nouns with each value. How does English express this information, if at all?

C. The witches’ line. Find Fair is foul, and foul is fair (Act I, Scene 1) in all three versions. Show each token’s text, lemma, POS, and morphology. What does each language do differently? Does spaCy make any mistakes?

D. Scripts. For each version, count how many words begin with a character from each script (LATIN, GREEK…). Are there any words in an unexpected script? What are they, and how might they have got there?

E. Meaning. Choose one WordNet category: animal.n.01, bird.n.01, weapon.n.01, food.n.01, or body_part.n.01. List the noun lemmas in your category in each version, using is_a() with the right language code (eng, fin, ell). Find one word that doesn’t belong, and the WordNet sense that let it in. Why might one version find far fewer words than the others?

Part 3: Reflection

In a short paragraph: do your differences come from the languages, or might some come from the translators, the fact that this is a play in verse, or the models?
