Input → Output

  • Output: the number 10
    • What comes back is called the return value
  • len() doesn’t care which string you give it: that’s what makes it reusable

More Than One Input

  • Some functions take two or more arguments, separated by commas:

Writing Your Own

Your First Function

def pluralize(noun):
    plural = noun + "s"
    return plural
  • def: “I’m defining a function”
  • pluralize: its name (you choose it)
  • (noun): the parameter, a variable that holds the input
  • : and indent: the body, just like for and if
  • return: what the function hands back

Defining Doesn’t Run Anything

  • Put pluralize in a chunk and run it
  • What happened?
  • Nothing! def only teaches Python the steps
    • Like writing down a recipe: nobody has cooked anything yet

Calling the Function

pluralize("cat")
  • Check: 'cats'

What Just Happened?

  • pluralize("cat"):
    1. Python jumps into the function, with noun = "cat"
    2. The body runs: plural = "cat" + "s"
    3. return plural sends "cats" back
    4. "cats" takes the place of pluralize("cat")
  • Call it again with "dog": same steps, new input

Calling the Function

  • You can store the return value in a variable, just like n = len(words)
animals = pluralize("hedgehog")
print(animals)

return vs. print

Two Versions of ttr

def ttr_print(words):
    print(len(set(words)) / len(words))

def ttr_return(words):
    return len(set(words)) / len(words)
  • Run both on test. What happens?

Now Use the Result

a = ttr_return(test)
print(a * 100)
b = ttr_print(test)
print(b * 100)

What happened?

  • For ttr_return: 80.0
  • For ttr_print: 0.8, then an error:
    • TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'
    • ttr_print showed you the number, but never gave it back
    • A function without return gives back None: “nothing”

The Rule

  • print() shows a value to you
  • return hands a value back to your code
  • If you want to use the result later (save it, plot it, put it in a DataFrame), you need return

Parameters

Two Parameters

  • We need to make an adjustment to our TTR function.
  • Remember how longer texts have lower TTRs? We need to compare the same number of words.
def ttr_first(words, n):
    return len(set(words[:n])) / len(words[:n])

Parameters

  • Arguments line up with parameters in order:
ttr_first(test, 3)
  • words = test, n = 3
    • Check: 1.0

Order Matters

ttr_first(3, test)
  • Check: TypeError: 'int' object is not subscriptable
    • Python tried to do 3[:test]
  • You can also name the arguments, and then the order doesn’t matter:
ttr_first(n=3, words=test)

Default Values

  • We often want the first 10,000 words. Let’s make that the default in defining our function:
def ttr_first(words, n=10000):
    return len(set(words[:n])) / len(words[:n])
  • Default parameter:
ttr_first(test)       # n is 10000
  • Parameter defined:
ttr_first(test, 3)    # n is 3

import re

def load_words(filename):
    with open("../../data/gutenberg/" + filename, "r", encoding="utf-8") as f:
        lines = f.readlines()

    while not lines[0].startswith("*** START"):
        lines = lines[1:]
    lines = lines[1:]

    while not lines[-1].startswith("*** END"):
        lines = lines[:-1]
    lines = lines[:-1]

    text = "".join(lines)
    words = re.split(r"[\W]+", text.lower())
    words = [w for w in words if w != ""]
    return words

def report(title, words):
    ttr = len(set(words)) / len(words)
    ttr_10000 = len(set(words[:10000])) / len(words[:10000])

    letters = 0
    for w in words:
        letters += len(w)

  • One function can do both: show you some things, and hand back what the code needs next

The Whole Thing

import re
import matplotlib.pyplot as plt

def load_words(filename):
    with open("../../data/gutenberg/" + filename, "r", encoding="utf-8") as f:
        lines = f.readlines()

    while not lines[0].startswith("*** START"):   # chop the header
        lines = lines[1:]
    lines = lines[1:]
    while not lines[-1].startswith("*** END"):    # chop the footer
        lines = lines[:-1]
    lines = lines[:-1]

    text = "".join(lines)
    words = re.split(r"[\W]+", text.lower())
    return [w for w in words if w != ""]

def report(title, words):
    ttr = len(set(words)) / len(words)
    ttr_10000 = len(set(words[:10000])) / len(words[:10000])

    letters = 0
    for w in words:
        letters += len(w)

    print(title, "TTR:", ttr)
    print(title, "TTR (10,000 words):", ttr_10000)
    print(title, "Average Word Length:", letters / len(words))
    return ttr_10000

alice_ttr_10000 = report("Alice", load_words("alice.txt"))
mansfield_ttr_10000 = report("Mansfield Park", load_words("mansfield_park.txt"))
odyssey_ttr_10000 = report("The Odyssey", load_words("odyssey.txt"))

plt.bar(["Lewis Carroll", "Jane Austen", "Homer (tr. Butler)"], [alice_ttr_10000, mansfield_ttr_10000, odyssey_ttr_10000])
plt.title("TTR Comparison: Alice vs Mansfield Park vs The Odyssey")
plt.xlabel("Author")
plt.ylabel("TTR")
plt.show()

        lines = lines[1:]
    lines = lines[1:]
    while not lines[-1].startswith("*** END"):
        lines = lines[:-1]
    lines = lines[:-1]

    text = "".join(lines)
    words = re.split(r"[\W_]+", text.lower())
    return [w for w in words if w != ""]

def report(title, words):
    print(title, "TTR:", ttr(words))
    print(title, "TTR (10,000 words):", ttr_first(words))
    print(title, "Average Word Length:", avg_word_len(words))
    return ttr_first(words)

  • IndentationError: the body of a function must be indented, just like a for loop
  • TypeError: ... missing 1 required positional argument: you gave the function fewer arguments than it has parameters

  • FileNotFoundError: is day27.qmd in the same folder as your Day 25 work?
  • ModuleNotFoundError: No module named 'lin301': is the file in data/, named exactly lin301.py? Did you run the sys.path.append("../../data") line first?
