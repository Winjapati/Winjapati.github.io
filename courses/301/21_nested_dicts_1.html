Two Lists, One Dict

Where We’ve Been

  • In the review, we went from a string → a list → a dict
  • A dict pairs things up: key : value
  • But often our data comes as two separate lists that already line up:
languages = ["Hittite", "Sanskrit", "Latin", "Gothic", "Tocharian"]
dates     = [-1650, -1200, -700, 350, 600]
  • How could we turn these into a single dict?

Predict the Output

  • We know how to loop through a list. What if we loop through both?
  • Before you run this: what do you expect attested to look like?
languages = ["Hittite", "Sanskrit", "Latin", "Gothic", "Tocharian"]
dates     = [-1650, -1200, -700, 350, 600]

attested = {}

for lang in languages:
    for date in dates:
        attested[lang] = date

print(attested)

What Went Wrong?

  • Let’s trace what happens when lang = "Hittite":
inner loop date attested["Hittite"]
1st turn -1650 -1650
2nd turn -1200 -1200
3rd turn -700 -700
4th turn 350 350
5th turn 600 600
  • The inner loop runs all the way through for every turn of the outer loop, overwriting the value each time.

Nested Loops

  • A loop inside a loop is a nested loop
  • For every one turn of the outer loop, the inner loop runs completely
for letter in ["a", "b"]:
    for number in [1, 2, 3]:
        print(letter, number)
  • Nested loops are very useful (more on that later today!), but they’re not what we want for lining up two lists.

Fix #1: Use the Index

  • We actually saw this, a few weeks back:
attested = {}

for i in range(len(languages)):
    attested[languages[i]] = dates[i]

print(attested)
  • range(len(languages)) gives us 0, 1, 2, 3, 4
  • So we grab item i from both lists at the same time
  • It works, but it’s a bit clunky to read.

Fix #2: zip()

  • zip() takes two (or more) lists and pairs up their items by position, like the two sides of a zipper
for lang, date in zip(languages, dates):
    print(lang, date)
  • Notice that we have two temporary variables: lang and date
  • On each turn, zip() hands us one item from each list

Fix #2: zip()

  • So building our dict looks like this:
attested = {}

for lang, date in zip(languages, dates):
    attested[lang] = date

print(attested)

Dict Comprehensions

  • Remember list comprehensions?
lengths = [len(lang) for lang in languages]
  • There’s a dict version too, using { } and key: value:
attested = {lang: date for lang, date in zip(languages, dates)}
print(attested)
  • Same result as the loop on the previous slide, in one line.
  • Use whichever one you find easier to read!

More Than Two Lists

  • zip() can line up as many lists as you like
  • If we want more than one value per key, we can put the values in a list:
languages = ["Hittite", "Sanskrit", "Latin", "Gothic", "Tocharian"]
dates     = [-1650, -1200, -700, 350, 600]
branch    = ["Anatolian", "Indo-Iranian", "Italic", "Germanic", "Tocharian"]

lang_info = {}

for lang, date, br in zip(languages, dates, branch):
    lang_info[lang] = [date, br]

print(lang_info)
  • How would you get Gothic’s branch?

Nested Lists

Nested Loops, Revisited

  • Nested loops weren’t the right tool for pairing up lists
  • But they’re perfect when our data has layers
  • A string is a sequence of characters. So a list of strings has two layers:
words = ["eeny", "meeny", "miney", "mo"]

for w in words:
    for c in w:
        print(c)
  • The outer loop goes through the words; the inner loop goes through the letters of each word.

Counting Inside the Inner Loop

  • We can count something for each word, then store it in a dict:
words = ["eeny", "meeny", "miney", "mo"]
vowel_counts = {}

for w in words:
    vowels = 0                 # reset the counter for each word
    for c in w:
        if c in "aeiou":
            vowels += 1
    vowel_counts[w] = vowels

print(vowel_counts)
  • Why does vowels = 0 go inside the outer loop, and not above it?

Nested Lists

  • A list can contain other lists:
sentences = [
    ["the", "cat", "sleeps"],
    ["the", "dog", "runs"],
    ["the", "bird", "flies"]
]
  • This is a natural way to store a text that has been split into sentences, and then each sentence into words

Looping Through Nested Lists

for sentence in sentences:
    for w in sentence:
        print(w)
  • Again: the outer loop gets a sentence (a list), the inner loop gets each word in it.

Indexing Nested Lists

  • We can index into each layer, one [ ] at a time:
sentences[1]
sentences[1][2]
  • What would sentences[2][1][0] give us?
