Nested Dictionaries

A Problem

  • On Monday we built this:
consonants = {
    "p": ["bilabial", "stop", "voiceless"],
    "b": ["bilabial", "stop", "voiced"],
    "s": ["alveolar", "fricative", "voiceless"]
}

consonants["s"][1]
  • What does consonants["s"][1] mean? Can you tell without scrolling back?
  • In six weeks, will you remember that [1] is manner?

A Dict Inside a Dict

  • What if each value were itself a dictionary, with labeled parts?
consonants = {
    "p": {"place": "bilabial", "manner": "stop", "voice": "voiceless"},
    "b": {"place": "bilabial", "manner": "stop", "voice": "voiced"},
    "s": {"place": "alveolar", "manner": "fricative", "voice": "voiceless"}
}
  • This is a nested dictionary: a dict whose values are dicts
  • The outer keys are the sounds; the inner keys are the features

Accessing Nested Items

  • Just like nested lists, we go in one layer at a time:
consonants["s"]
consonants["s"]["manner"]
  • Compare: consonants["s"][1] vs. consonants["s"]["manner"]
  • Which would you rather read?

When to Use Nested Dictionaries

  • Use them when one thing naturally has several labeled parts:
students = {
    "Alice": {"quiz": 9, "homework": 10, "final": 8},
    "Ben":   {"quiz": 7, "homework": 9, "final": 10}
}
  • What would students["Ben"]["final"] give us?
  • What other linguistic data could you store this way?

Building a Nested Dict with zip()

  • Usually we don’t type these out by hand. We build them from lists:
phonemes = ["p", "b", "t", "d", "k", "g"]
place    = ["bilabial", "bilabial", "alveolar", "alveolar", "velar", "velar"]
manner   = ["stop"] * 6
voice    = ["voiceless", "voiced", "voiceless", "voiced", "voiceless", "voiced"]

stops = {}

for ph, pl, m, v in zip(phonemes, place, manner, voice):
    stops[ph] = {"place": pl, "manner": m, "voice": v}

print(stops)
  • What does ["stop"] * 6 do?

Adding & Changing Items

  • Adding a new outer key works just like a regular dict:
stops["q"] = {"place": "uvular", "manner": "stop", "voice": "voiceless"}
  • And we can change (or add) an inner value by going two layers in:
stops["p"]["aspirated"] = True
print(stops["p"])

Looping Through Nested Dicts

Looping Through a Dict

  • When we loop through a dict, we get its keys:
for ph in stops:
    print(ph)
  • To get each key and its value, we can use .items():
for ph, features in stops.items():
    print(ph, features)
  • Look familiar? Two temporary variables, just like with zip().

Looping Through a Nested Dict

  • Here, features is itself a dict, so we can look inside it:
for ph, features in stops.items():
    print(ph, "is", features["voice"])

Asking Questions of Our Data

  • Combine a loop with a conditional to search the data:
for ph, features in stops.items():
    if features["voice"] == "voiced":
        print(ph)
  • Compare with Monday’s version: if consonants[c][2] == "voiced":

Counting with a Nested Dict

  • Our counting pattern works here, too:
place_counts = {}

for ph, features in stops.items():
    pl = features["place"]
    if pl in place_counts:
        place_counts[pl] += 1
    else:
        place_counts[pl] = 1

print(place_counts)

Lists of Dicts

Another Way to Nest

  • A nested dict needs a unique key for each item
  • But what if two items share a name?
lexicon = {
    "bank": {"pos": "noun", "gloss": "edge of a river"},
    "bank": {"pos": "noun", "gloss": "place to keep money"}
}
print(lexicon)
  • What happened to the river?

A List of Dicts

  • Instead, we can make a list, where each item is a dict:
lexicon = [
    {"form": "bank", "pos": "noun", "gloss": "edge of a river"},
    {"form": "bank", "pos": "noun", "gloss": "place to keep money"},
    {"form": "bank", "pos": "verb", "gloss": "to tilt an airplane"}
]
  • Each dict is one entry: one row of a table
  • Each key ("form", "pos", "gloss") is a column

Looping Through a List of Dicts

  • Since it’s a list, we loop through it as normal; each item is a dict:
for entry in lexicon:
    print(entry["form"], "(" + entry["pos"] + "):", entry["gloss"])
  • And lexicon[2]["gloss"] gives us…?

Building a List of Dicts

  • We build one with .append(), just like any list:
rows = []

for ph, features in stops.items():
    rows.append({
        "phoneme": ph,
        "place": features["place"],
        "voice": features["voice"]
    })

print(rows)
  • Hang on to this idea: on Friday, we’ll see that this is exactly the shape pandas wants for building a table.

Dict of Dicts vs. List of Dicts

Dict of dicts List of dicts
Looks like {"p": {...}, "b": {...}} [{...}, {...}]
Find one item Fast: d["p"] Loop and check
Keys Must be unique Duplicates are fine
Good for Lookup tables, inventories Entries, tokens, rows
